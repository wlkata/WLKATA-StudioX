# WLKATA StudioX

WLKATA StudioX is a desktop app for programming and controlling WLKATA robotic arms on Windows, macOS, and Linux.

## Features

- Program visually with Blockly and Python.
- Jog the robot and record teaching positions.
- Preview motion in a shared 3D world.
- Export programs as G-code.
- Connect through USB serial or Wi-Fi.
- Add features through optional extensions.

## Download

Open this repository’s Releases page and download the asset for your system:

| Platform | Package |
|---|---|
| Windows | .exe |
| macOS | .dmg — choose Apple Silicon or Intel |
| Linux | .AppImage or .deb |

Download an installer from the release assets. The automatically generated source archives are not application installers.

Python is bundled with the app; no separate Python installation is required.

## Getting started

Install and launch StudioX, connect your robot, and choose Command, Blockly, or Teaching from the sidebar. Use World to preview motion before running on hardware.
